# Weather announcements

RetroCast voiceovers and alert tone from weather.com/retro (downloaded by
`scripts/fetch-weather-music.sh`). Played on native page changes:

| File | Native page |
|------|-------------|
| `current.mp3` | Current |
| `local.mp3` | *(unused — stock clip says "36-hour forecast")* |
| `extended.mp3` | 5-Day |
| `regional.mp3` | Regional |
| `radar.mp3` | Radar (NWS RIDGE regional loop) |
| `alert-tone.mp3` | Alerts page (`native.alert_style: page`) |
